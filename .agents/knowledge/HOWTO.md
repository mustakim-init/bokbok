# Knowledge Base

Non-obvious things an AI discovered about this codebase. Read this before starting work, write to it when you learn something.

## When To Write

- You figured out how a complex part of the code works
- You discovered an architectural pattern used in the project
- You found a clever solution that's worth remembering
- You learned something about the project setup or dependencies

## File Naming

One file per topic. Name it clearly:

```
hilt-di-patterns.md
webrtc-signaling-flow.md
innertube-api-structure.md
data-store-preferences.md
```

## Template

```markdown
# [Topic]

## Context
What is this about? Which part of the codebase?

## What I Learned
The key insight or understanding.

## Code Example
```kotlin
// relevant code snippet
```

## Files Referenced
- path/to/file.kt (line numbers if helpful)

## Tags
`hilt`, `webrtc`, `innertube`, etc.
```

## How To Search

Before starting work, grep this folder for keywords related to your task. If you find something relevant, read the full entry.
